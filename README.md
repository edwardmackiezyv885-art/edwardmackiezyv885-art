### 你好，我是 LBW

自建 AI API 中转服务，把 Claude、GPT、DeepSeek、GLM、Kimi、Grok 这些模型接到一起，
包括几个特调的破甲版本。同时维护一套面向新手的接入文档和实测数据。

**站点**

- [lbwapi.online](https://lbwapi.online) — 模型实测、接入教程、报错排查
- [lbwapishop.online](https://lbwapishop.online) — API 控制台（注册即送试用额度）

**在做的事**

- 持续实测各家模型（延迟、稳定性、破甲效果），数据公开
- 把客户端配置流程做成可执行脚本，让不懂技术的人也能跑通
- 记录踩过的坑，写成人人能看懂的排查表

**项目**

| 仓库 | 说明 |
| --- | --- |
| [lbwapi-workbench](https://github.com/edwardmackiezyv885-art/lbwapi-workbench) | AI 客户端工作词包与技能树的一键安装工具 |
| [prompt-forge](https://github.com/edwardmackiezyv885-art/prompt-forge) | 结构化提示词生成器，单文件零依赖 |
| [turing-whitepaper](https://github.com/edwardmackiezyv885-art/turing-whitepaper) | 技术白皮书整理 |

**技术栈**

`Python` `Node.js` `Caddy` `PostgreSQL` `Docker` `new-api`
